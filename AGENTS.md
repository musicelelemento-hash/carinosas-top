## 🏛️ MATRIZ INTEGRAL DE HABILIDADES ACTIVAS

Este repositorio cuenta con un ecosistema de **37 habilidades de alta especialización** organizadas en dos categorías:
1. **Paquete Maestro de 20 Skills de Élite** (Planificación, 3D, Scroll, Pentesting y Memoria).
2. **Ecosistema de 17 Skills de Plataforma** (Supabase, Vercel, Cloudflare, Composio, Sentry, Neon).

## ⚡ PARTE II: ECOSISTEMA DE 17 SKILLS DE PLATAFORMA

### 1. Base de Datos & Backend Serverless
* **`sql-optimization`:** Diagnóstico con EXPLAIN, diseño de índices compuestos/parciales, resolución de N+1 y paginación keyset.
* **`supabase`:** Reglas maestras para Auth, Realtime, Storage, Edge Functions y SSR.
* **`supabase-postgres-best-practices`:** Optimización de índices, RLS, prevención de bloqueos y tuning de consultas Postgres.
* **`claimable-postgres`:** Bases de datos temporales efímeras instantáneas sin tarjeta vía Neon.
* **`neon-postgres-branches`:** Ramificación de base de datos para pruebas seguras de migraciones.

### 2. Infraestructura de Borde & Seguridad
* **`cloudflare`:** Plataforma de borde, Workers, Pages, CDN y redes.
* **`turnstile-spin`:** Protección antibot Cloudflare Turnstile en formularios de registro y publicación.
* **`workers-best-practices`:** Arquitectura de microservicios y webhooks de latencia ultra baja.

### 3. Frontend & Framework Next.js / React 19
* **`vercel-react-best-practices`:** Patrones de rendimiento, RSC boundaries y hooks de React 19.
* **`deploy-to-vercel`:** Despliegues automatizados y generación de previsualizaciones en vivo.
* **`vercel-optimize`:** Optimización de costes, bundles y Core Web Vitals.
* **`vercel-composition-patterns`:** Componentes compuestos escalables y patrones de contexto limpios.
* **`web-design-guidelines`:** Auditoría de accesibilidad, contrastes y usabilidad web.

### 4. Automatización, Observabilidad y Calidad
* **`composio`:** Orquestación con más de 1000 aplicaciones SaaS (Stripe, Telegram, GitHub, Linear, Slack).
* **`sentry-nextjs-sdk`:** Configuración de Sentry en App Router de Next.js.
* **`sentry-debug-issue`:** Diagnóstico automatizado a partir de stack traces reales.
* **`sentry-instrument`:** Instrumentación de errores, trazas y métricas.
* **`webapp-testing`:** Pruebas E2E de interfaz de usuario con Playwright.

## 🔄 PIPELINE DE EJECUCIÓN OBLIGATORIO PARA CADA TAREA

Cualquier agente que opere en este repositorio debe seguir estrictamente este pipeline de 6 fases:

```
┌─────────────────────────────────────────────────────────────┐
│ 1. INVESTIGACIÓN Y PLAN ([task-planner.md])                 │
│    Lectura estricta sin mutaciones. Crear plan detallado.   │
└──────────────────────────────┬──────────────────────────────┘
                               │
┌──────────────────────────────▼──────────────────────────────┐
│ 2. EVALUACIÓN DE SEGURIDAD ([security-and-auth.md])          │
│    Verificar RLS, sanitización, Turnstile y protección de datos. │
└──────────────────────────────┬──────────────────────────────┘
                               │
┌──────────────────────────────▼──────────────────────────────┐
│ 3. DESARROLLO Y TDD ([tdd-workflow.md] + [frontend-design.md])│
│    Escribir código limpio, tipado estricto y diseño de lujo.│
└──────────────────────────────┬──────────────────────────────┘
                               │
┌──────────────────────────────▼──────────────────────────────┐
│ 4. OPTIMIZACIÓN ([performance-and-caching.md] + [web-quality])│
│    useTransition, índices compuestos y caché eficiente.     │
└──────────────────────────────┬──────────────────────────────┘
                               │
┌──────────────────────────────▼──────────────────────────────┐
│ 5. VERIFICACIÓN OBLIGATORIA ([verification-before-completion])│
│    npm run build + linter + playwright tests en verde.      │
└──────────────────────────────┬──────────────────────────────┘
                               │
┌──────────────────────────────▼──────────────────────────────┐
│ 6. CONTROL DE VERSIONES ([git-workflow-and-commits.md])      │
│    Conventional Commits y sincronización limpia en GitHub.  │
└─────────────────────────────────────────────────────────────┘
```
